# Big & Small: The Sunken Garden

A two-player co-op puzzle adventure in the browser. A stone Golem and a tiny Sprite cross a ruined garden together to bring its fountain back.

**Play:** open the GitHub Pages link for this repo on a laptop or desktop.

- **One keyboard:** Golem uses WASD, Space, E. Sprite uses the arrow keys, Enter, Right Shift.
- **Online (two laptops):** one player creates a room, the other joins with the 4-letter code. The game connects the two browsers directly (WebRTC via PeerJS), so no server is needed.

Single HTML file, Three.js from a CDN, everything else generated in code.
